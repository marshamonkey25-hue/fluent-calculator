# Windows 11 风格跨平台计算器

Status: resolved

## Problem Statement

用户希望在 Windows、macOS 和 Linux 桌面上使用一个熟悉的 Windows 11 风格计算器，获得一致的计算方式、布局和键盘体验。目标涵盖完整的日常计算、科学计算、程序员计算、日期计算与单位换算，而不是只有外观或少数可点击按钮的演示程序。

原版应用依赖 Windows 技术栈，不能直接作为 QML 跨平台应用运行。独立重写普通浮点计算逻辑也难以保持原版的数值精度、连续按键、求值顺序和错误恢复行为。用户需要可维护的完整源码、构建说明以及在当前机器上实际可运行的交付物。

## Solution

以固定的微软 Calculator 公开源码版本为参考，移植其 C++ 算术核心，以 Qt 6 和 QML 重建 Windows 11 Fluent 风格的应用内容。在三个目标平台上使用系统原生窗口外框，提供浅色、深色和跟随系统主题，以及简体中文、英文和跟随系统语言。

实现 18 个功能入口：标准、科学、程序员、日期计算、函数绘图，以及货币、体积、长度、重量和质量、温度、能量、面积、速度、时间、功率、数据、压力、角度这 13 类换算。除已明确接受的差异外，各模式的布局、按键、运算与交互遵循固定参考源码。

首版函数绘图覆盖多条 `y=f(x)` 曲线、平移缩放与坐标查看。货币换算采用独立的每日参考汇率来源，显示来源和数据日期，支持联网刷新及离线缓存。这两项不承诺与微软商店发行版完全等价。

交付完整源码、必要的授权声明、构建运行说明和本机可运行构建。跨平台设计与跨平台实测分开报告，不将 Linux 上成功运行描述为三个平台均已验证。

## User Stories

3. 作为桌面用户，我希望窗口外框与所在操作系统一致，以便正常使用系统的窗口移动、缩放和关闭操作。

## Implementation Decisions

### 已确认的产品与架构决策

- **固定参考版本。** 以微软 Calculator 公开源码提交 `79e1ac53bba690cdf930e5dcd6ed9dbc4cbfb128` 为行为和布局基准。该基准不等同于已验证的 Microsoft Store 发行版本。
- **技术栈。** 使用 Qt 6、QML、C++ 和 CMake，面向 Windows、macOS、Linux。最低 Qt 版本、操作系统版本及架构支持在实现时根据依赖和实际验证记录，不提前声称未测试的组合受支持。
- **计算核心。** 移植原版算术管理层、计算引擎及任意精度算术能力，通过 Qt 适配层向 QML 暴露用户操作和可观察状态；保留适用的 MIT 版权及第三方声明。平台相关依赖需要实际移植验证，不能假定原版工程可直接跨平台编译。
- **界面模块。** 包含导航与设置、三种算术模式、日期计算、函数绘图、换算、历史和内存面板。它们属于同一应用交互模型，不需要为每个页面另建一套计算规则。
- **界面与核心交互。** 界面发出模式选择、按键、历史与内存操作等用户意图，应用层提供显示内容、可用操作、错误、历史和内存等状态。表达式和数值在桥接过程中不得被强制转换为 JavaScript 普通浮点数而损失核心能力。
- **各模式求值。** 标准模式逐步求值，科学模式遵循优先级与括号，程序员模式遵循整数位宽与进制。此前提出的统一表达式计算方案已由“跟随原版各模式行为”取代。
- **外观与语言。** 系统原生窗口外框，内部采用 Fluent 布局；浅色、深色和跟随系统主题；简体中文、英文及跟随系统语言。标题栏和桌面特效不要求跨系统完全相同。
- **函数绘图边界。** 替代实现多条 `y=f(x)` 曲线、平移、缩放和坐标查看。绘图使用独立的函数求值与采样能力，不要求将科学模式的逐次按键引擎直接作为绘图引擎。无定义点、非法表达式和不连续区间必须有真实处理。
- **交付。** 提供完整源码、构建与运行说明、本机可运行版本及验证报告；本轮不要求三平台安装包。

### 从固定参考源码继承的行为

- 标准和科学模式各维护最多 20 条历史，超限删除最旧记录；程序员模式没有计算历史收集器。
- 算术模式共享最多 100 条内存值，新值在前，超限删除最旧值。普通模式切换保留会话中的历史和内存。
- 普通启动不自动恢复前次历史和内存。保存最近模式及界面偏好；这与 Windows 特有的显式活动快照恢复是不同流程。
- 标准与科学模式使用各自的核心精度和输入计数规则，参考常量分别为 16 和 32；这些值不代表底层只有普通浮点精度。沿用核心的指数输入、括号深度、边界和错误检查。
- 科学模式默认角度制。程序员模式默认十进制、64 位，并支持 64/32/16/8 位；输入范围按位宽和进制决定。
- 换算遵循参考类别、单位、输入及数字格式规则。温度、功率、角度允许负值，其余类别按参考限制处理。换算使用的数值策略与任意精度算术核心区分，不承诺所有换算值以任意精度存储。
- 键盘映射、连续等号、运算符替换、错误恢复、历史复用和内存命令以固定参考实现及其测试为行为依据。

### 本规格补全的实施建议

以下内容用于使规格可执行，不表示用户在此前访谈中已逐项确认供应商或接口设计。

- **汇率来源建议。** 采用 Frankfurter v2 混合每日参考汇率，使用公开 HTTPS 服务，无需 API 密钥。微软正式版的数据源不纳入复用，不承诺报价、覆盖币种或更新时间完全一致。
- **汇率契约。** 请求指定基础货币和目标货币，消费带数据日期、基础货币、目标货币及汇率的记录，在本地计算换算金额。验证响应结构、货币对和有效数值，只有有效数据可替换缓存。
- **汇率状态。** 进入货币模式先展示已有缓存并尝试刷新，提供手动刷新；更新过程不阻塞界面。网络或服务异常时保留缓存，未有缓存时显示不可用。显示来源、实际观测日期和最近刷新时间，不能把下载时间当成汇率日期。
- **汇率范围与归属。** 使用服务当前有效货币和实际可取得的报价；历史币种、缺失货币对及不同观测日期不能伪装成统一有效报价。记录数据来源和适用条款；软件 MIT 授权不自动等于所有上游数据具有相同许可。
- **状态保存。** 界面偏好、最近模式和有效汇率缓存使用本地持久化；历史与内存按参考行为保留在会话中。无需新增服务器或远程用户账户。
- **测试可控性。** 应用的汇率数据源与时间读取允许测试环境提供固定数据；生产交互与测试经过同一应用逻辑，避免为测试另建业务实现。

## Testing Decisions

### 首选测试边界

以**完整应用的用户操作与可观察结果**作为主要测试边界：使用真实 QML 界面及其应用逻辑发起按键、模式切换、设置、换算和绘图操作，断言显示结果、错误、可用操作、历史、内存及图形状态。优先覆盖跨模块完整行为，而不是分别 mock 计算核心、Qt 适配层和每个页面。

当前仓库没有应用代码或既有测试边界，因此该边界为本规格建议。它未被描述为用户已单独批准的接口设计。网络数据和时间是保证测试确定性所需的外部替换点，不是新增业务模块。

### 好的测试与既有参考

- 好的测试通过公开用户操作验证可观察行为，在内部类、函数组织或存储结构变化后仍有效。不检查私有成员、内部调用次数或实现细节，也不复制待测算法充当期望值。
- 覆盖真实的 QML 界面、Qt 应用逻辑与移植核心之间的集成。对无法通过界面高效覆盖的大量数值边界，补充通过计算核心公开命令接口运行的上游用例；该补充只用于精度和移植回归，不为每个内部模块建立新测试层。
- 仓库尚无测试可复用。固定的微软源码包含 C++ 与 C# 行为测试，可作为按键序列和预期结果的依据；这些上游测试尚未在本项目运行，不得当作已通过的项目证据。
- 本机临时 Qt 探针已验证 CMake 模块发现、简单 C++ 编译，以及 offscreen 和 Wayland 下的 QML 按钮点击与图像捕获。这仅证明测试工具可用，不能证明计算器功能或视觉一致性。

### 行为覆盖与验收

- **模式与导航：** 全部 18 个入口可达且有真实功能；切换后标题、按键和可操作状态正确，没有旧模式状态造成的错误操作。
- **标准与科学：** 同一输入 `2 + 3 × 4` 分别得到 `20` 和 `14`；覆盖括号、连续等号、百分比、正负号、清除与退格、结果后继续计算和错误后恢复。覆盖能够暴露普通浮点桥接精度损失的数值，并依据核心参考结果检查显示。
- **科学边界：** 覆盖角度切换、常见科学函数、非法定义域、指数输入和括号深度限制。期望值依据上游用例或独立已知数学结果，避免将实现输出录制后直接作为正确性证据。
- **程序员：** 覆盖各进制及位宽、合法输入、最高位和符号解释、边界整数、位运算及移位。采用参考行为确定溢出与截断预期。
- **历史与内存：** 验证标准和科学历史隔离、程序员无历史、20/100 条边界及淘汰顺序、跨模式保留、复用与清空。通过普通关闭和重新打开验证历史/内存不恢复、偏好保留。
- **日期：** 验证同日、跨月、跨年、闰日以及年/月/日加减；月底调整和反向日期遵循参考规则。
- **单位换算：** 全部 12 类非货币换算均有实际用例；覆盖已知比例、温度偏移、同单位转换、允许和禁止的负值，以及输入/显示边界。数值容差依据换算策略明确规定，不用精确字符串比较替代所有数值验证。
- **汇率：** 使用固定响应和可控时间测试成功刷新、来源与日期显示、缓存读取、首次离线、已有缓存离线、缺失报价、格式损坏、错误货币对与无效数值；失败响应不得覆盖有效缓存。常规测试不依赖实时网络，真实服务连接检查与确定性测试分开报告。
- **函数绘图：** 覆盖已知函数、多曲线添加/修改/删除、平移缩放和坐标读取；验证无定义区间与渐近线不会被错误连线，非法输入不会导致界面失去响应。不用仅检查“生成了一张图片”代替图形正确性。
- **界面与输入：** 检查鼠标和键盘入口、焦点、禁用状态、复制结果、宽窄窗口、两种语言以及浅色/深色/跟随系统主题。视觉检查聚焦内容区域，容许原生窗口外框和字体渲染的平台差异。
- **交付验证：** 本机完成实际构建、启动及适当自动测试，记录版本和运行方式。截图与参考对照、人工操作和自动测试分别注明；Windows/macOS 未经验证的部分明确列出。

所有范围内的入口都必须实际工作；只有界面、固定示例结果、静态曲线或未接入行为的按钮不满足验收。若移植或依赖限制影响某项功能，应记录具体差异和验证证据，不能静默缩减范围后宣称完成。
