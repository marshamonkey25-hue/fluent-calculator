# 01: 运行真实核心驱动的标准计算器

**What to build:** 用户能够构建并启动具有原生窗口外框、Fluent 风格 QML 内容的桌面计算器，通过鼠标和键盘完成真实的标准模式四则运算。以这一完整操作路径验证微软核心在本机的移植、界面连接与数值传递。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Spec:** Windows 11 风格跨平台计算器。

**User stories:** 1, 3, 10, 11, 13, 17, 20, 66, 67。

- [ ] 使用 Qt 6、QML、C++ 和 CMake 建立可在当前 Linux 环境构建、启动和关闭的应用；保留面向 Windows/macOS 的可移植结构，明确记录实际验证平台和依赖版本。
- [ ] 固定并移植微软源码版本 79e1ac53bba690cdf930e5dcd6ed9dbc4cbfb128 的算术核心，保留来源、移植说明及适用版权和第三方声明；不得以独立 JavaScript 浮点计算代替真实核心。
- [ ] 标准模式具备数字、小数、四则运算、等号和清空操作；计算值、表达式和错误状态通过实际应用逻辑显示，鼠标与对应键盘输入遵循同一行为。
- [ ] 标准模式按步骤求值，连续输入 2 + 3 × 4 = 得到 20；核心与界面之间的数值传递保留原版精度能力。
- [ ] 内容采用可扩展的 Fluent 风格基础布局和导航方式，窗口外框保持系统原生行为；后续模式可以接入，不以未实现页面冒充已完成功能。
- [ ] 新界面文案可翻译、样式可随应用主题变化，合理缩放窗口时必要操作仍可访问；不要求本任务完成独立的设置页面。
- [ ] 通过真实 QML 操作验证基本计算、清空和键鼠一致性，并覆盖能够发现数值桥接精度损失的参考用例；测试断言外部行为而非内部实现。
- [ ] 提供从依赖准备到构建、运行和执行现有检查的说明，并记录一次实际启动及测试结果；本任务不将其他平台标记为已实测。
