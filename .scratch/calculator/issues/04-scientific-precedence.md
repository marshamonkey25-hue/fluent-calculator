# 04: 使用科学模式的优先级与括号

**What to build:** 用户可以从导航进入科学模式，输入带括号的计算，看到表达式和结果，并获得与标准模式不同的优先级求值行为。

**Blocked by:** 01: 运行真实核心驱动的标准计算器。

**Status:** ready-for-agent

**Spec:** Windows 11 风格跨平台计算器。

**User stories:** 21, 26。

- [ ] 导航可进入真实科学模式，并可返回标准模式；模式名称、显示区域和可用按键与当前模式一致。
- [ ] 通过移植核心处理数字、小数、基础运算与括号，保留科学模式的表达式显示和输入语义，不以自建浮点表达式计算替代核心。
- [ ] 科学模式对 2 + 3 × 4 求值得到 14，标准模式对应逐步运算得到 20；括号能够正确改变运算顺序。
- [ ] 沿用科学模式的精度、输入和括号深度检查；对未闭合或不合法的输入按固定参考版本处理，并能恢复继续输入。
- [ ] 科学模式与标准模式切换后不产生错误的求值策略或过期显示；页面沿用主题、可翻译文案、键盘规则和宽窄窗口布局。
- [ ] 从真实 QML 操作验证模式切换、运算优先级、嵌套括号、输入边界及错误恢复；输入行为和期望结果可追溯到固定参考版本。
