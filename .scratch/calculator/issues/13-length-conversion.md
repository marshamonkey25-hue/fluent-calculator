# 13: 完成长度换算

**What to build:** 用户可进入长度换算，选择源单位和目标单位，输入数值并得到格式正确的真实结果；这一完整流程成为其他换算类别的可复用交互。

**Blocked by:** 01: 运行真实核心驱动的标准计算器。

**Status:** ready-for-agent

**Spec:** Windows 11 风格跨平台计算器。

**User stories:** 46, 47, 55。

- [ ] 从导航进入可用的长度换算，具备参考源/目标单位、输入、清除与结果展示，单位与比例可追溯到固定参考版本。
- [ ] 改变输入或单位后计算真实结果，支持同单位转换；参考允许的输入侧切换或单位交换操作保持结果与状态一致。
- [ ] 遵循长度类别的符号、输入位数和显示规则，包括小值、大值、舍入及必要的科学计数形式；换算数值策略不冒充算术核心的任意精度能力。
- [ ] 非法输入和不可显示结果有明确状态，纠正后能正常换算；按钮和键盘入口遵循相同规则。
- [ ] 换算交互能够复用于后续类别而不复制整套输入和格式逻辑，但本任务必须先完整交付长度换算，不能只交付抽象框架。
- [ ] 页面沿用主题、可翻译单位名称与说明，以及宽窄窗口布局。
- [ ] 通过真实界面验证已知比例、往返转换、同单位、小数、非法负值、输入位数和显示边界，容差按数值策略明确规定。
