# 11: 计算两个日期的差值

**What to build:** 用户可从导航进入日期计算，选择两个日期并查看符合参考规则的差值结果。

**Blocked by:** 01: 运行真实核心驱动的标准计算器。

**Status:** ready-for-agent

**Spec:** Windows 11 风格跨平台计算器。

**User stories:** 32, 34。

- [ ] 提供真实日期计算入口和起止日期选择，输入变化后更新差值与必要说明，不使用静态示例结果。
- [ ] 结果的单位、组合格式及同日和反向日期处理以固定参考版本为准，不能自行将所有日期差简化为近似月数或年数。
- [ ] 正确处理跨月、跨年与闰日；使用日历日期语义，避免因时区或夏令时将一天误计为不同天数。
- [ ] 无效或超出支持范围的日期有明确且可恢复的状态，日期控件不允许不可解释的输入。
- [ ] 日期页面沿用 Fluent 风格、主题和可翻译文案，键盘可操作日期控件，宽窄窗口均可访问结果和输入。
- [ ] 从界面选择日期并验证同日、反向、跨月、跨年和闰年差值；使用固定日期数据，不依赖测试运行当天。
